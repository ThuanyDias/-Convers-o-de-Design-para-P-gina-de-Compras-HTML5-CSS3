# 🛍️ Projeto 3 – Conversão de Design para Página de Compras

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de transformar um design de cliente em uma página web funcional utilizando apenas **HTML5 e CSS3**.

O foco principal foi aplicar boas práticas de estruturação e estilização, reforçando conceitos fundamentais de desenvolvimento Front-End.

---

## 🧠 Habilidades Desenvolvidas

Durante o desenvolvimento deste projeto, consolidei conhecimentos em:

### 📌 Estrutura com HTML5
- Organização semântica dos elementos
- Inserção e otimização de imagens
- Estruturação clara e organizada do layout

### 🎨 Estilização com CSS3
- Controle de tipografia (`font-size`, `line-height`)
- Espaçamentos com `margin` e `padding`
- Ajustes de layout com `width` e `height`
- Responsividade com `@media screen`
- Uso de `max-width` para imagens adaptáveis
- Alinhamento de texto com `text-align`
- Controle de layout com `display` e `position`
- Interatividade visual com `cursor` e `opacity`
- Customização de botões
- Organização visual e hierarquia de informações

---

## 📱 Responsividade

O projeto foi adaptado para diferentes tamanhos de tela utilizando media queries:

---
css
@media screen and (max-width: 768px) {
    /* Ajustes para dispositivos menores */
}

---
Garantindo melhor experiência em dispositivos móveis.
